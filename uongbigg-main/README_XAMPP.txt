UONG BI GO - XAMPP + MYSQL

1. Mo XAMPP -> Start Apache va MySQL.
2. Copy thu muc uongbigo_xampp vao C:\xampp\htdocs\
3. Mo http://localhost/phpmyadmin
4. Import database.sql
5. Mo http://localhost/uongbigo_xampp/
